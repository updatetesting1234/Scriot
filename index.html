What this does
When ON:
· Response body is AES-256-GCM encrypted immediately after fetch, before being held in memory
· Raw plaintext is zeroed out after encryption
· Decrypted only at render time, held briefly then discarded
· Session key lives only in this tab — never written to disk, localStorage, or logs
· On tab close or Purge, key and ciphertext are wiped

Network bytes still travel to your device (unavoidable in a browser) but the response body is never plaintext in JS memory for more than milliseconds.
